Runtime companion 0.2

Durability, without another contract system

Contracts define meaning. Interoperability connects live applications. The runtime adds admission, persistence, retries, recovery, and honest outcomes when effects cannot be known.

Read the runtime profile See an example
Model

Define, connect, admit, recover

Each layer has one job, so applications can consume the same types and contracts without implementing a workflow engine.

  1. 01

    Contracts define

    Record, event, and action artifacts share one identity, SemVer, schema, digest, and conflict model.

  2. 02

    Applications connect

    Verified interoperability declarations bind live sources and handlers to exact artifacts.

  3. 03

    Runtime admits

    Policy selects one provider and pins exact contract, source, provider, and handler evidence.

  4. 04

    Durability recovers

    Runs, attempts, leases, timers, cursors, and outcomes survive crashes without guessing.

Example

Readable requirements, exact admitted evidence

Authors name behavior and a compatible version. The runtime writes the exact digests and implementation identities during admission. 

type: runtime_workflow
id: canvas.zone.set-status
version: 1.0.0
name: Set status from canvas zone
enabled: true

triggers:
  - id: drop-on-status-zone
    event:
      id: canvas.drop
      version: ^1.0.0

steps:
  - id: patch-task-status
    action:
      id: mdbase.record.patch
      version: ^2.0.0
    input:
      path:
        $expr: event.data.file.path
      patch:
        status:
          $expr: event.data.zone.id

The event is an ordinary structured CloudEvent.

The action uses the shared request, invocation, and outcome envelopes.

The admitted plan pins exact contracts and one selected provider before dispatch.
