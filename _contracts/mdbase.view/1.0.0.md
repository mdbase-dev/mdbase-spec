# Saved view

A record exposed through `mdbase.view` stores shared query scope and one or more
stable named views. Each named view resolves to the query model in Chapter 11.
Optional `presentation` metadata is advisory and does not alter headless query
results.

Implementing this contract is how a collection declares which of its records
are saved views. A tool that advertises `view_records` discovers and executes
views through this contract's type implementations, not through a reserved type
name, path, or frontmatter value.

This artifact is passive. Implementing it grants no authority to read, execute,
or modify any record.
